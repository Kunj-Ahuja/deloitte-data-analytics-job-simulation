## 📊 Project Overview

This project analyzes industrial telemetry data from **Daikibo Industrials** to identify patterns in machine downtime across its factories and device types.

The project was completed as part of the **Deloitte Data Analytics Job Simulation** on Forage, where the objective was to transform raw telemetry data into meaningful operational insights using Tableau.

The analysis focuses on identifying:

- Which Daikibo factory experienced the highest downtime
- Which device types contributed most to downtime
- How downtime is distributed across factories
- How factory-level selection affects device-level analysis
- Potential operational areas that may require further investigation

---

## 🎯 Business Objective

Daikibo Industrials collects telemetry data from machines operating across multiple factories.

Management wants to understand where machine downtime is occurring and which types of devices are contributing most to it.

The objective of this analysis was therefore to create an interactive Tableau dashboard that allows decision-makers to:

1. Compare downtime across factories.
2. Identify the factory with the highest downtime.
3. Drill down into device-level downtime.
4. Quickly identify machines that may require further investigation.

## 🗂️ Dataset

The dataset contains telemetry records generated by Daikibo's industrial equipment.

Each telemetry record contains information including:

- `deviceID`
- `deviceType`
- `timestamp`
- `location`
- `factory`
- `section`
- `status`
- `temperature`

The telemetry data records the operational status of machines over time.
